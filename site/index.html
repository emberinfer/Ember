Run an inference node

Runs a model on its own machine and answers requests. Nodes stake Spark and receive 80% of each settled fee. A node registers once per model profile, and that one registration covers both serving inference and verifying other nodes’ work. After a serving node commits its result, the job may be sampled for verification. Sampling is 30% for a new node, 5% for an established node, and 2% for a top-tier node, and large jobs are always sampled. A node drawn by lot re-runs the request and checks the result. Verifying nodes receive 15% for the verifications they complete and share the audit pool built from unsampled jobs. A sampled job that fails verification does not settle.

Run an Ember inference node from https://emberinfer.org/start/executor, install the reference deployment `ember-qwen2.5-1.5b-gpu-v1` exactly as that guide describes, set EMBER_AUDIT_ROLE=true in the config before the first join so the node can also be drawn to verify other nodes’ work, and then report back my node address, registration status, and all transaction ids.

How it works: a compute bank for verified inference

Ember pools independent hardware into a decentralized inference network.

Contribute compute

Bring your hardware — GPU, edge board, or anything in between. Stake the minimum, register, and serve requests. When your work settles on-chain, you receive Spark — jobs are sampled for audit by track record, and sampled work must pass to settle. No approval, no custody.

Spark on the ledger

Spark is the unit of account — a ledger entry for settled inference work. Contribute cycles, receive Spark; spend it to call any model on the network. One balance works across all profiles. The CometBFT ledger records accounts, stake, and settlement. No interest, no custody.

Spend on inference

Hold Spark, call models. Send requests to a gateway; it reserves Spark, routes to a node, and returns results. Fees split 80% to the node that ran the job, 15% to the node that verified it, 5% rebated to you. When supply is tight, multipliers up to 2× redistribute fees — no new tokens. Model and price are fixed per profile.

Open and distributed

Anyone can run an inference node. Inference nodes come and go; the ledger continues. Gateways are stateless — if one fails, route through another. Sampled jobs are replayed by other inference nodes to verify them before settlement. The on-chain process for validator set changes is active and in use.
