Use

Obtain a current authenticated gateway address, bearer token and funded account from the deployment operator. Submit OpenAI-compatible chat completions; whole-model and MoE requests support true SSE streaming. The repository copy does not publish verified live connection addresses.

Freeze a bounded hold, execute, commit evidence, resolve sampled audit and settle actual tokens. Gross settled fees allocate 80% to execution, 15% to audit and 5% back to the caller.

Serve

Join permissionlessly with compatible artifacts, runtime, stake and capacity. Registration offers execution and on-chain audit eligibility by default; per-function opt-outs are declared at registration. There is no deregistration or mid-term role removal. Live registrations lapse after 200,000 blocks.

Keep your identity for exit: stop renewal, wait for registration lapse and pending liabilities, unbond, wait for release height, then claim. See the exit procedure.

Models and profiles

A model is one set of weights. A profile is a deployment form: Whole model or Sharded (by layer, by expert, or layer + expert). Unified profiles cover whole-model and sharded forms under one card. CPU/GPU is a node attribute. The 1.5B segmented entry point belongs to its unified profile.

Release checks

For release downloads, set EMBER_VERSION=0.7.0; follow the Quickstart for download checks and installation.

v0.7.0 provides Linux amd64/arm64 archives, the Engine SPI kit, SHA256SUMS and release-signing.pub. SHA256SUMS.sig is not yet published; the signing key is offline. Checksum comparison checks downloaded bytes but does not authenticate unsigned sums.

The repository root key measures 8f93347f50a04c2d3b420ebde2d7cd73fc792386b18c20e5a0f60f6d47706e09. Its checked-in trust statement names an older key, and the detached signature fails verification against the current statement bytes. It does not authenticate the current release key. Status and limits

Reference live block time is about 1.5–1.9 seconds, segmented execution about 1.02 seconds/token and a short 35B request about 10–12 seconds end-to-end. These are reference observations, not guarantees. Ordinary requests expose needed plaintext to gateways, execution nodes and auditors. Signatures, sampling and consensus do not eliminate collusion, key or supply-chain risks.
